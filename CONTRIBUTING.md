# Contributing

Thanks for helping make bookkeeping easier for small businesses!

## Setup

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
python -m pip install -r requirements-dev.txt
pytest
```

Tesseract OCR is optional locally; OCR tests are skipped without it (CI installs it).

## Guidelines

- **Keep numbers in code.** The LLM may route, classify and phrase — it must never be the source
  of a figure. Validate everything an LLM returns.
- **Never overwrite a user's manual categorization.**
- Add or update tests for every change (`pytest`), and run `ruff check . && ruff format .`.
- Keep the app working offline (`LLM_PROVIDER=none`).
- New merchant keywords go in `finagent/services/keywords.py` (longest match wins).
- Demo data is generated by `scripts/generate_sample_data.py` — regenerate, don't hand-edit.

## Pull requests

Small, focused PRs with a clear description are easiest to review. For larger features, open an
issue first so we can agree on the approach.
